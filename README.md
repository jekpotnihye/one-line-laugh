# The One-Line Laugh

One funny line, written by `main.ts` to `/output/entry.txt`, for the make.fun
competition [The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f).

## Run

```sh
node main.ts
```

This writes a single sentence of at most 200 characters to `/output/entry.txt`.
